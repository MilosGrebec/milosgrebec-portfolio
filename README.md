# Miloš Grebec · Portfolio

Personal portfolio built with React and Vite. Content lives in `src/App.jsx`, styles in `src/styles.css`, and the public CV in `public/Milos_Grebec_CV.pdf`.

## Run locally

Use Node.js 22 or newer.

```sh
npm ci
npm run dev
```

## Deploy

```sh
npm run build
```

Publish the contents of `dist/` to the web root. Existing URLs such as `/projects`, `/about`, and `/newproject` have lightweight redirects to the corresponding sections. Email is a direct mail link and needs no service credentials.
